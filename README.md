# 传染病报告规则（2026年版）

> 中国疾病预防控制中心 · 2026年版

本仓库为《传染病报告规则（2026年版）》的 Web 电子书源代码，包含甲乙丙类共 **47 种传染病**的报告规则，支持搜索、书签、批注、备注、高亮等功能。

## 项目结构

```
├── index.html          # 主页面（HTML 结构）
├── assets/
│   ├── style.css       # 样式表（CSS）
│   └── app.js          # 交互逻辑（JavaScript）
└── README.md           # 项目说明
```

## 功能特性

- 📖 支持甲、乙、丙类传染病分类浏览
- 🔍 实时搜索传染病名称或内容（支持 Ctrl+K 快捷键）
- 🔖 书签功能（标记常用章节）
- 🖊️ 文本批注与备注
- 🎨 多色高亮标记（黄、绿、蓝、粉、橙）
- 📱 响应式设计，支持移动端

## 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 数据来源

中国疾病预防控制中心，2026年版传染病报告规则。
